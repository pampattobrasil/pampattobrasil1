# Empório Pampatto Brasil — projeto pronto para GitHub Pages

## Estrutura

- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/images/`

As imagens dos produtos foram ajustadas para mostrar somente as carnes, sem os nomes incorporados no rodapé. A tela de login usa `assets/images/login-logo.png`.

## Como publicar do zero

1. Exclua os arquivos antigos do repositório ou crie um repositório novo.
2. Extraia este ZIP.
3. Envie **o conteúdo extraído**, mantendo `index.html` e a pasta `assets` na raiz.
4. Em **Settings > Pages**, selecione `Deploy from a branch`, branch `main` e pasta `/(root)`.
5. Aguarde o deploy terminar em **Actions**.
6. Abra o site e pressione `Ctrl + F5` para evitar cache da versão anterior.

Não envie apenas a pasta `assets`: o `index.html`, o CSS e o JavaScript devem ser da mesma versão.
